Case notes

  1. 1
    COS 1.2 Search by username prefix, up to 20 results. POST /api/friend/search
  2. 2
    COS 1.2 The button depends on relationship: Send request (none), Accept (incoming), Request sent (outgoing), Friends (friend). Your own name shows no button. A request can also be sent from a profile page.
  3. 3
    COS 1.3 Errors show inline under the search, using the FRIEND_ERRORS text, and nothing is saved. A user who blocked you shows the same “User not found” error.
  4. 4
    COS 1.2 Accept adds both users as friends. Decline removes the request with no notice to the sender. /request/accept, /request/decline
  5. 5
    COS 1.2 Only unanswered requests appear here. /request/cancel
  6. 6
    COS 1.4, 1.6 Each friend shows live activity (Offline, Online, In a lobby for a game, or Playing a game), updated within a few seconds. Only friends can see it. Message opens the chat window. Remove asks to confirm, then updates both users.
  7. 7
    Each section has its own empty state. The page updates live from friendsUpdated.
  8. 8
    COS 1.1 Shown only to unverified users. Sending requests and messages is blocked until the email link is used. Links expire after 24 hours; Resend sends a new one.

Case notes

  1. 1
    COS 1.6 Opens with the newest 50 messages, oldest at the top. This button loads the next page. POST /api/conversation/open, /history
  2. 2
    COS 1.6 Every message shows the sender and time. New messages arrive live from dmNewMessage in every tab.
  3. 3
    COS 1.6 Send is disabled when the box is empty or only spaces, and the counter warns near 1000. The server checks again on dmSend.
  4. 4
    COS 1.6, 1.9 If the server rejects a message (too long, or flagged by moderation), it isn’t delivered, the text stays in the box, and the dmError reason shows here.
  5. 5
    COS 1.4 After a friend is removed, history stays readable and the composer is replaced (canSend: false). Open question 5 in the spec.
  6. 6
    COS 1.8 Report a user or a specific message with a reason; reports are saved for moderators. Block removes the friendship and stops requests, messages, invites, and private-game joins. Wired up in T32.
